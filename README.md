# Catálogo Interativo

Catálogo online moderno e responsivo com painel administrativo integrado e envio direto de pedidos para o WhatsApp.

## 🚀 Tecnologias

- **React 19**
- **TypeScript**
- **Vite**
- **Tailwind CSS v4**
- **Lucide React** (Ícones)

## 📦 Como Executar o Projeto

1. Clone o repositório:
```bash
git clone https://github.com/SEU_USUARIO/SEU_REPOSITORIO.git
cd SEU_REPOSITORIO
```

2. Instale as dependências:
```bash
npm install
```

3. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```

4. Acesse no navegador:
- **Catálogo do Cliente:** `http://localhost:3000`
- **Painel Administrativo:** `http://localhost:3000/admin`
  - Senha inicial padrão: `abc1234`

## 🛠️ Scripts Disponíveis

- `npm run dev`: Inicia o ambiente de desenvolvimento.
- `npm run build`: Compila a aplicação para produção na pasta `dist/`.
- `npm run preview`: Visualiza o build de produção localmente.
- `npm run lint`: Executa a verificação estática de tipos do TypeScript.
